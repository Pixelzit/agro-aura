Storefront Child Theme
======================

Installation:
1. Make sure the official WooCommerce Storefront theme is installed.
2. Go to WordPress Dashboard > Appearance > Themes > Add New > Upload Theme.
3. Upload storefront-child.zip.
4. Activate "Storefront Child".

Customization:
- Add custom CSS to style.css.
- Add PHP customizations/hooks to functions.php.
- Copy Storefront template files into this child theme only when template overrides are needed.

Parent Theme:
Storefront
Template slug: storefront
